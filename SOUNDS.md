# Sound files

Every sound in the game points at a plain mp3 path under `sounds/` (relative to `index.html`). The files shipped here are tiny placeholder tones — drop your real audio in with the **same filename**, or rename a file and change its path in the sound table in the game script (`RX.SND` in the server script, `MUSIC` / `AMBIENCE` / `blip` in the client script). A missing file is skipped silently.
